A deterministic, standard-library-only Python program that draws a newspaper front page summing up the world news of Thursday 19 November 2026 — Anthropic's record $81.3 billion IPO and its Nasdaq debut as ANT, Hakeem Jeffries' nomination as the first Black Speaker of the House, the EU's proposed 45 billion euro Ukraine loan, the Kerch Bridge hit a third time, Trump's arrival in Shenzhen for a trilateral APEC summit, the ICJ's Rohingya genocide judgment, the worldwide rollout of GTA VI, and Saudi Arabia lifting its missile alerts — as a single 1024×1024 PNG. It writes the image with its own embedded 5×7 bitmap font and a hand-written PNG encoder, so two runs produce identical bytes with no network access.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

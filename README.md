One picture of Thursday 19 November 2026, drawn by a small Python program that uses nothing but the standard library. The front page carries eight stories from that day: Anthropic's record $81.3 billion IPO and its first Nasdaq trade as ANT, Hakeem Jeffries' nomination as the first Black Speaker of the House, the EU's proposed 45 billion euro loan for Ukraine, the Kerch Bridge struck a third time, Trump's landing in Shenzhen for a trilateral APEC summit, the ICJ's Rohingya genocide judgment, the worldwide launch of GTA VI, and Saudi Arabia lifting its missile alerts. The glyphs live in the code as one short string per character and the PNG is encoded by hand, so the program writes identical bytes on every run, with no network access.

## How to run it

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```

That writes `out/entry.png` (1024×1024). Without the variable, the image goes to `/output/entry.png`.
